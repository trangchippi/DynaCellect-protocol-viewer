Open one or more protocol .json files, or try the built-in example.

How to use this viewer

1. Open protocols

  • Click Open protocol(s) or drop one or more DynaCellect .json files on the page. Each protocol gets its own tab at the top; use the × to close it.
  • Load example opens a small built-in protocol so you can look around.
  • Everything happens on your computer; no file is uploaded. Rotea protocols are not supported yet.

2. Data entries

  • If the protocol has data entries (for example a dilution volume), type your values in the box under the tabs. Volumes, times and bag needs update straight away.
  • They start at each entry's minimum value, so set them to your run before reading any numbers.

3. Steps view

  • Pick a step in the list on the left, or use Previous / Next or the arrow keys.
  • The drawing shows the kit: the blue path goes from the FROM line to the TO line through the pump. Bags show their volume after the step; a red outline means the bag runs out, orange means over capacity.
  • The right side lists the step's settings, checks and the bags at that step. The left shows rocker and magnet, like the instrument screen.

4. List view

  • All steps in one table. Filter by text, show only steps with warnings, click a row to open the step, copy the table or download it as CSV.

5. Bag preparation

  • Shows which line each bag connects to, how much to prepare, and the largest volume the bag will hold during the run (liquid plus air), which tells you the smallest bag to use.
  • Type the volume you will prepare and the bag capacity in the table, or use Use protocol start volumes / Use recommended start volumes.
  • Print / save as PDF prints only this sheet.

6. Simple and Advanced bag preparation

  • Simple: one table with a single number per bag, using the data entries and start volumes you have set.
  • Advanced: for runs where an input varies (for example how much cell suspension you load). Tick what varies and give low and high values. The sheet then shows, per bag, the volume the bag needs at the start as a range, a recommended range to prepare, the peak liquid and air, and the largest volume it will hold.
  • Each step is labelled: Fixed (a set volume), Small fixed (a flush or priming push, 30 mL or less), Priming (ends when liquid reaches the sensor), Flexible (ends when the bag runs dry, so it takes whatever the bag holds), Data entry (set by a data entry), Air, or No pump. Fixed, small and priming steps set the minimum a bag must hold; flexible steps set the range.
  • Steps whose volume changes when a varying input changes are marked var in the step list and show what they depend on, so you can follow a flexible input into the later steps that use its liquid.

7. Info and Compare

  • Info: protocol details including the software version, kit setup, data entries and variables.
  • Compare: choose two open protocols. Steps are matched by name, so an inserted step stays one row; only changed cells are highlighted, and the changes can be copied as a list.

What it can do

  • Estimate step times and volumes from the protocol (volume ÷ flow rate, or the set duration).
  • Track how much liquid and air each bag holds through the run and warn when a bag runs out or may be too small.
  • Show the fluid path and settings of every step, and compare protocols.

What it cannot do

  • It is not validated and does not replace the instrument, the user guide or your own procedures. It has been checked against only a few real runs.
  • It does not include liquid held in the tubing, cell losses, or the time people take to respond to prompts and pauses.
  • Where a protocol gives a volume as a range or text (for example "30-200 mL"), you must enter the real volume or mark it as varying. In Advanced mode the ranges come from running the protocol at the low and high ends of the inputs you tick (all combinations for up to four inputs); this is a practical envelope, not a proof that no other combination is worse.
  • Tubing volumes (including the line between the kit and the bag) are not included, so a small amount of extra liquid may be needed for priming and flushing. Liquid you add to a bag during a prompt (for example rinse buffer) is also unknown to the page.
  • Air pushed into a bag is assumed to stay there (a worst case). The bubble sensor notes are based on an assumed reading of the sensor names and are only hints.
  • The kit drawing is a schematic, not to scale. The kit (isolation or bead removal) is detected from the protocol.

What varies from run to run?

Tick the inputs that are not fixed (for example the cell input volume) and give their low and high values. The page then runs the protocol at the low and high ends and shows ranges. Inputs you leave unticked use the single value you have set. If the same quantity appears twice (for example a cell input data entry and the cell input bag), tick only one of them or give both the same range.
