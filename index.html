About this view

Schematic only (not to scale), drawn after the instrument's fluid-path screen and the kit tubing figures in the user guide. Bubble sensor 1 sits just left of the pump; sensor 2 is on line A (both kits). Which sensor a step uses is read from the name in the file (no suffix = sensor 1, _2 = sensor 2, _both = both); that reading is an assumption. Times are estimates: volume ÷ flow rate, or the set duration; prompts and waiting for the user are not included.
